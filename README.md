## The entry

One line — the funniest honest error message an appliance could show.
A toaster, reporting the truth about a jammed slice:

> ERROR E04: Bread jammed in slot 2. I toasted it four times anyway. It is charcoal now. Stop pressing the lever.

111 characters, one line. The laugh comes out of the fault itself: the
bread jammed, the toaster kept doing its job anyway, and now it is charcoal.
Flat, put-upon, and entirely plausible — exactly what the machine would say.

## How it works

`main.ts` (Node 22.18+, run as `node main.ts`) writes the line to
`/output/entry.txt` and validates it first: 1–200 characters, UTF-8,
non-blank, single line. No network, no dependencies, no secrets.

```sh
node main.ts
cat /output/entry.txt
```
